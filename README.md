# Geolocation-Based Attendance Tracking System

Developed as part of academic project at ATME College of Engineering, Mysuru.

## Overview
Attendance system using GPS geofencing + face recognition to stop proxy attendance.

## Tech Stack
- Backend: Python, Django 4.2.7, Django REST Framework
- Database: MongoDB (djongo), MySQL
- Face Recognition: OpenCV, dlib, face-recognition library
- Frontend: HTML, CSS, JavaScript

## Features Implemented
- GPS based campus verification
- Facial recognition for identity verification
- Role based dashboard - Student, Staff, Admin
- Automated attendance reporting
- Real-time verification
